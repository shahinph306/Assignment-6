Prject Name:
FitLog - Workout & Fitness Tracker

Project Overview:
FitLog is a modern, responsive web application built with Next.js that helps users explore workout routines, create personal fitness plans, and manage saved exercises seamlessly.

Technologies Used:
Framework: Next.js (App Router)
Language: TypeScript / JavaScript
Styling: Tailwind CSS & DaisyUI
Icons: Lucide React
Notifications: React Toastify
Deployment: Vercel

Key Features:
Interactive Workout Directory: Explore various structured workout routines with smooth dynamic routing.
Custom Plan Builder: Easily add workouts to your personal daily plan with live badges updating in the Navbar.
Saved Routines & Local Storage: Save favorite exercises with local persistence so data remains on browser refresh.
Real-time Toast Notifications: Instant visual feedback using React Toastify when adding or removing workouts.
Fully Responsive Dark UI: Optimized user interface designed for mobile, tablet, and desktop screens.
